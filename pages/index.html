Варикапне налаштування вхідного контуру FM-приймача

Діапазон 88–108 МГц · розрахунково-графічна робота, КПІ ім. Ігоря Сікорського, РТФ, група РЕ-41

Напруга налаштування варикапа, вибірковість контуру, пригнічення дзеркального каналу та вимоги до точності джерела напруги. Усі результати на цій сторінці автоматично збираються з однієї програмної моделі після кожної зміни коду.

Інтерактивний конспект Повзунки параметрів, живі графіки й висновок. Python працює просто в браузері, перше завантаження — до хвилини. Звіт (Word) Модель, 11 рисунків, таблиці, висновки — 13 сторінок. Код на GitHub Модель, тести, збірка однією командою uv run fm-build.
